# CodeChef Solutions

Independent C and C++ solutions to CodeChef programming exercises. Each source file is a separate console program named for its problem.

## Usage

Compile one solution at a time, for example `g++ -std=c++17 TEST.cpp -o /tmp/codechef-test`, then run it with the problem input. There is no package installation or single application build.
